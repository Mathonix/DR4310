## 继续改进：精简主控与自动使能 · 2026-10-10

### 审查与改动

- 主界面压缩为连接 / 链路选择、电机 ID、四模式、单个表盘、目标、启停及关键读数。连接详情与驱动说明移到设置；曲线、功率、量程、归零 / 反向和波形默认折叠；侧栏仪表、故障详情、数据记录移到调试并折叠。去掉主页重复母线徽章、功率徽章、增益提示和重复小表盘 SVG。状态 / 当前故障仍直接显示，电流读数固定为 A，避免 Kt 换算后失去原始电流信息。保留亮暗主题、手机单列及急停空间。
- 新增 `src/auto-enable.ts`，将运行时开关状态与安全停机顺序集中管理。CAN 直接复用 `nativeAutoEnable`；串口复用命令格式器发送 `AE 1/0`，由原 UART 请求队列等待 `@OK AE`。开启始终确认，不受「操作确认」偏好关闭影响；无反馈 / 故障时拒绝开启，旧固件不开放开关。
- 优先展示新鲜串口 INFO 的 `ae=` 实际值；CAN 仅接受同 ID 串口回读。无回读显示「已发送 ·」及 title 说明，发送失败不冒充确认状态。按 CAN ID 保存发送状态，重连清除缓存，命令前的旧 INFO 不覆盖新状态。
- 安全入口立即把开关复位，递增开关会话并取消传输 / UART 待发请求，防止迟到的开启结果恢复 UI。普通 CAN 停止为 `08 00 → 00`；CAN 急停为 `08 00 → 03 → 03`；串口为 `AE 0 → STOP`，即使 AE 关失败也继续尝试停机。保留 GM 零帧、双链路独立停止、Esc、隐藏 / 关闭看门狗、反馈中断、故障、总线异常与主动断开前停机；切模式 / 链路 / ID 时也处理自动使能正在发送的情况。AE 开启纳入反馈看门狗，INFO 回报的上电自动使能也纳入监测；运行时 AE 发送未确认会尝试停止。
- `BOOT_AE` 仅在固件参数表实际返回该键时显示为设置中的「上电自动使能」选项；原数字输入保留为内部参数暂存，界面不重复显示。勾选仅标记修改；同步走原 `SET → SAVE` 流程，开启写入要求确认，未收到 SAVE 成功不会宣称已持久化。运行时 AE 不保存到 localStorage / Flash，也不改 BOOT_AE。
- 浏览器脚本更新为主页连接入口和 `data-testid`，移动控件先切视图 / 展开折叠区；补充自动使能确认、回读及急停顺序检查。假设备模拟 AE 开启时忽略停止，避免测试设备掩盖漏发 AE 关的问题。
