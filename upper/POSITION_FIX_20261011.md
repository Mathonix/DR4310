线上地址：https://dr4310.233688.xyz/

## 复现与修复

在修改前的线上页面注入模拟 Web Serial 设备，实际位置为 1.25 rad，输入目标 3 rad：

- 遥测已含 PosRad 时，启动错误地发送 `POS 1.25`，覆盖了用户目标。
- 默认 16 路遥测不含 PosRad，虽发送 `POS 3`，位置读数仍为空，启动需要未知位置确认。

修复后，已输入或通过表盘设定的目标会保留；未设置目标时启动保持当前位置。支持 TCH 的串口固件自动将 PosRad 加入当前通道表，保留 16 路宽度及其他通道的顺序，读回确认后等待有效位置样本。遥测关闭或频率为 0 时在 RAM 中启用反馈，不自动 SAVE。准备期间可以取消启动；缺少有效样本时不发送运动命令。旧固定通道固件保留未知位置确认。

修改前本地源码重新构建的 app.js 与原线上资源哈希相同，已有本地改动均保留。

## 当前固件的控制结构

当前位置模式是位置 → 速度 → Iq 电流的串联级联。位置 PID 输出与轨迹规划器的速度前馈相加后形成速度目标，随后速度环产生 Iq 目标。因此位置 Kp/Ki/Kd 全为 0 不等于电机无输出。运行中清零 Ki 也不会清除已积累的积分状态；模式切换时才重置外环和轨迹状态。

串口 `POS` 命令只带目标，使用电机内的 POS_KP/POS_KI/POS_KD。调试页位置帧的 Kp/Ki/Kd 随 CAN 0x500+ID 发送，不能据其为 0 推断串口使用的参数也为 0。

本次修改上位机的目标与反馈流程，固件控制算法未改动。
