# DR4310 上位机

用于在浏览器中控制和调试 DR4310 电机。

- Web Serial 串口与 PCAN-USB WebUSB 连接。
- 电流、速度、位置和 MIT 控制。
- PID、电流限制和轨迹速度前馈配置。
- 实时曲线、遥测查看和日志导出。
- 设备状态、故障查看与急停。
- 齿槽补偿：网页发起双向低速标定、曲线预览、导入导出、上传校验与保存。

串口默认 **200000，8N1**，需要使用相同波特率的固件；也可选择 230400 匹配旧固件。Chrome/Edge 中连接串口后，打开 **参数配置 → 驱动参数 → 齿槽补偿标定**，确认空载、可整圈旋转及外部控制停止，点击 **开始双向标定**。默认每方向 0.2 rad/s、2 圈、电流上限 0.2 A，约 2 分 15 秒。完成后依次点击 **上传并保存**、**启用补偿并保存**。

标定期间保持页面在前台。停止按钮、Esc、页面隐藏或串口断开都会取消标定；扫描临时使用 1000 ms 通信超时。连接正常时，完成/取消后恢复原电流限制、过载、指令时间、通信超时、遥测配置和原补偿开关，保持电机停止。上传后补偿关闭，单独启用后生效。上传会备份原表，并检查电机 ID、换相配置和 CRC；保存会一并保存当前设备参数。

开发验证：`npm run typecheck` 会先生成客户端 bundle，干净检出无需保留本机生成文件；随后执行 `npm test`。实机浏览器测试须显式执行 `npm run build:pages` 和 `npm run test:hardware:cogging -- --run`，会驱动 COM5 电机，测试专用 stdio 桥默认连接真实 UART 200000，可通过 `--port COM6 --baud 230400` 指定匹配的串口和波特率；正式网页不使用此桥。测试记录写入项目 `logs/cogging_hw_20261013/browser/`。

电流音频：打开顶部「电流音频」，按下面的顺序操作：

1. **选择音乐**：可选择 MP3、WAV、FLAC 等浏览器支持的音乐，也可选择现成的 `.raw` / `.pcm` / `.s16` / `.s16le`。普通音乐会在浏览器本地解码、重采样为 8000 Hz、声道平均为单声道、编码为有符号 16 位小端（S16LE），再去除直流偏置。不会上传文件或由电脑扬声器播放。RAW 必须原本就是 8 kHz、单声道、无文件头的 S16LE。
2. **下载或直接播放**：文件就绪后可点击「下载 S16LE RAW」。转换和下载不需要连接电机，最长 5 分钟；普通音乐文件最大 64 MiB。浏览器不支持的格式或损坏文件会显示解码错误，并清除之前的待播文件。
3. **设置最高电流**：连接与固件匹配的串口，通过数字输入或滑块设置音频峰值上限。3.4.5 固件允许 Q 轴最高 2000 mA、D 轴最高 1500 mA；网页按 INFO 能力限制，旧固件沿用其公布的上限，缺少字段时最多 200 mA。切换轴或固件能力下降时自动收紧数值。普通 IQ_LIM 仍生效，所选峰值超过它时网页会提示并禁止播放；当前 IQ_LIM=1.9 A，使用 Q 轴 2 A 前须将它设为至少 2 A。默认值 5 mA，小幅短测最多 5 mA。
4. **开始播放**：确认电机已固定、无危险负载且急停可用，可先点击「300 Hz 小幅短测」，再点击「播放文件」。暂停、停止、Esc、切离页面和断开均由音频会话处理；结束后确认停机并恢复遥测。保持页面在前台。

固件 3.4.5 / 200000 的短 TX 模式会通过 OPEN 自动协商并在播放时显示，使用 4096 样本缓冲、12 帧窗口和 100 ms STATUS。3.4.4 已通过完整 RAW 的 D 轴 1 mA、101.27 秒验证；3.4.5 的 Q/D 各 1 秒、1 mA 小声验证通过。J-Link 回传仍有坏 CRC STATUS，不能称链路完全无错误。见 [实现与验收记录](../docs/AUDIO_UART_V1_IMPLEMENTATION.md) 和 [2 A / 1.5 A 扩展](../docs/AUDIO_2A_EXTENSION.md)。

转换浏览器验证：`npm run build:pages` 后执行 `npm run test:ui:audio:convert`；测试环境需要 Chromium 与 ffmpeg（仅用于生成 WAV/MP3/FLAC 测试文件，正式网页不依赖 ffmpeg），设备通信为模拟，不驱动实机。报告和界面截图写入 `logs/continue_task2_20261014/`。

实机音乐工具可指定其他串口：`npm run test:hardware:audio -- --run --port COM6 --axis D --amplitude-ma 1 --out ../logs/audio-com6`。工具会驱动电机，须实际确认测试条件；只换串口名称不代表链路已验证。正式网页通过浏览器选择串口，不依赖测试桥。
